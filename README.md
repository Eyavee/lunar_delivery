# 🚀 Лунная доставка

**Лунная доставка** — это стратегическая игра-симулятор, в которой вы управляете лунной базой и отправляете роверы на доставку грузов по поверхности Луны. Ваша цель — заработать максимум денег, удержать рейтинг базы и продержаться 10 дней.

---

## 🎮 Как запустить игру

1. **Установите Python 3.8 или новее**  
   Проверьте версию: `python --version`

2. **Установите Pygame**  
   Выполните в терминале: `pip install pygame`

3. **Скачайте проект**  
   Скачайте ZIP-архив или клонируйте репозиторий:  
   `git clone <https://github.com/Eyavee/lunar_delivery>`

4. **Перейдите в папку проекта**  
   `cd lunar_delivery`

5. **Запустите игру**  
   `python main.py`

## 🧠 Что сделано в проекте

### Графический интерфейс (Pygame)
- Окно 1400×800 пикселей.
- Левое меню с информацией о базе, роверах и заказах.
- Карта Луны с кратерами, зонами риска и анимированными объектами.
- Роверы визуально реализованы как луноходы (колеса, антенны, фары, солнечные батареи).
- Заказы отображаются в виде кружков с иконкой груза, цвет зависит от срочности.
- Всплывающие сообщения с эмодзи (поддержка через отдельный шрифт).

### Игровая механика
- **Управление**: клик по роверу → клик по заказу → ПРОБЕЛ для доставки.
- **Анимация движения**: роверы плавно едут к заказу, забирают груз и возвращаются на базу.
- **Заказы**: генерируются случайно с разным весом, наградой, срочностью и риском.
- **Зоны риска**: красные полупрозрачные области, увеличивающие риск заказа.
- **Цель игры**: продержаться 10 дней, заработать деньги и не потерять рейтинг.

### Хранилище данных (в памяти)
- Все данные хранятся в словарях Python (эмуляция базы данных).
- Состояние игры, роверы, заказы, история доставок — в объекте `GameData`.

## ⚙️ Логика веса, риска и доставки

### Вес груза
- Каждый заказ имеет вес (от 2 до 28 единиц).
- Ровер имеет грузоподъёмность (5, 15 или 30 единиц).
- Если вес заказа превышает грузоподъёмность ровера — доставка **невозможна**.

### Расход батареи
Формула расчёта:
```
total_cost = (distance / 10) + (risk * 5) + (weight * 0.3)
```
- **distance** — расстояние от ровера до заказа (в пикселях).
- **risk** — риск заказа (0.1–1.0, умножается на зональный множитель).
- **weight** — вес груза.
- Если `total_cost` > текущей батареи ровера — доставка **блокируется**.

### Риск и неудача
При выполнении заказа есть шанс неудачи:
```
if random.random() < risk * 0.3:
```
- При риске 1.0 → 30% шанс провала.
- При риске 0.5 → 15% шанс.
- При провале: награда уменьшается вдвое, ровер теряет дополнительные 20 батареи.
- Если батарея падает ниже 20 — ровер **ломается** навсегда (статус `"broken"`).

### Особые условия
- Если расстояние > 500 пикселей **и** риск > 1.0 — доставка **всегда невозможна**.
- Зоны риска на карте умножают базовый риск на 1.5, 1.8 или 2.0.

## 📂 Где и какие данные хранятся

| Файл | Что хранит |
|------|------------|
| **`settings.py`** | Константы: размеры экрана, цвета, зоны риска, параметры роверов, настройки анимации, позиции объектов. |
| **`game_data.py`** | Класс `GameData`: состояние игры (день, деньги, рейтинг), словарь роверов, словарь заказов, история доставок. Все данные в оперативной памяти. |
| **`game_logic.py`** | Класс `GameLogic`: вся бизнес-логика — проверка возможности доставки, расчёт батареи, выполнение доставки, генерация новых заказов, переход на следующий день, анимация движения. |
| **`ui.py`** | Класс `UI`: отрисовка всех элементов интерфейса (меню, карта, роверы, заказы, зоны риска, сообщения), обработка кликов мыши, поддержка эмодзи через отдельный шрифт. |
| **`main.py`** | Класс `LunarDeliveryGame`: главный игровой цикл, обработка событий, обновление состояния, рендеринг, управление сообщениями. |

## 🤖 Что использовали из AI

В процессе разработки проекта были использованы следующие возможности AI:

- **Генерация структуры проекта** — AI помог спроектировать архитектуру игры (разделение на файлы по ответственности).

- **Оптимизация фона** — AI предложил добавить шумовую текстуру на карту для реалистичности.
- **Документация** — AI помог написать этот файл `README.md` и структурировать информацию.

## 🧪 Особенности реализации

- **Анимация роверов**: движение к заказу и обратно с индикатором прогресса и эффектом пыли.
- **Поддержка эмодзи**: отдельный шрифт для смайликов, чтобы они отображались во всех элементах интерфейса (меню, карта, сообщения).
- **Зоны риска**: на карте отображаются полупрозрачными красными областями, влияют на риск заказов внутри них.
- **Генерация новых заказов**: после выполнения доставки или в начале игры создаётся новый заказ со случайными параметрами.
- **Сохранение данных**: в текущей версии данные не сохраняются между сессиями (хранятся только в памяти), но структура позволяет легко добавить сохранение в JSON или SQLite.
